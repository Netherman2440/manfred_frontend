A quiet way to ask the agent to remember.

Slash commands let you trigger out-of-band actions without sending a message to the LLM. /summarize asks Manfred to fold the recent conversation into long-term observations. The call is synchronous — we wait, we show, we get out of the way.

Behavior
  • Dropdown appears as soon as the field contains /. List filters live by name prefix.
  • ↑/↓ move the selection; Enter runs the selected command and consumes the keystroke (does not send a message).
  • Esc closes the dropdown but leaves the text. Typing anything that no longer matches a command also closes it; pressing Enter then sends as a normal message.

Why this and not a generic spinner
  • The field's border breathes slowly (2.4s ease cycle) so the user can tell the system is alive without it feeling like a hung progress bar.
  • Input and attach are dimmed and locked. The send button morphs into a spinner — same shape, different content, no layout jump.
  • A dashed divider opens beneath the field with a one-line status: italic ~ mark + "Recollecting" + animated dots + a quiet meta line setting the expectation that this is a 20-second operation, not a 200ms one.
